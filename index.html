PROJECT OVERVIEW

Turning Student Data Into Insights

The project explores how academic performance, educational background and employability indicators can be used for placement outcome prediction.

🎯

Objective

Build a machine learning classification system to predict student placement status based on available academic and employment-related attributes.

📊

Data Analysis

Process structured student data, prepare input features and examine relevant academic and employability indicators.

🤖

Prediction

Train and evaluate multiple classification algorithms and generate placement predictions from compatible input records.

MACHINE LEARNING

Algorithms Behind The Prediction

Three classification techniques are implemented to explore different approaches to placement prediction.

01 / CLASSIFICATION

Logistic Regression

A supervised learning algorithm used to estimate the probability of a student belonging to a placement outcome category.

02 / CLASSIFICATION

Support Vector Machine

A supervised learning approach that identifies a decision boundary to separate different placement outcome classes.

03 / CLASSIFICATION

Decision Tree

A tree-based algorithm that makes predictions using a sequence of feature-based decision rules.

HOW IT WORKS

From Dataset To Prediction

A structured machine learning workflow for placement outcome classification.

STEP 01

Data Upload

Load the student placement dataset in CSV format.

STEP 02

Preprocessing

Separate input features and target, split the dataset and apply standard scaling.

STEP 03

Model Training

Train Logistic Regression, SVM and Decision Tree classifiers.

STEP 04

Prediction

Use a compatible test dataset to predict placement outcomes.
